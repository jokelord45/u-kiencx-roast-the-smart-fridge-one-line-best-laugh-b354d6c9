## The entry

> My smart fridge screams if its door stays open ten seconds, yet it has watched me eat cold pizza over the sink for three years without a word.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt` — UTF-8, one line,
142 characters, inside the 1–160 character gate.

```sh
node main.ts
cat /output/entry.txt
```
